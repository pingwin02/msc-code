# Master Degree Code Repository

This repository contains source code and projects completed during the second cycle (Masters's degree) studies from 2025 to 2026 at Gdańsk University of Technology (Gdańsk Tech).

---

## Semester Structure & Folder Descriptions

### Semester 1
- **AOW** – Multi-objective Optimization Algorithms (Algorytmy optymalizacji wielokryterialnej)
- **SOWW** – High-Performance Computing Systems (Systemy obliczeniowe wysokiej wydajności)
- **ZTAI** – Advanced AI Techniques (Zaawansowane techniki AI)

### Semester 2
- **MISS** - Modelling and Simulation of Systems (Modelowanie i symulacja systemów)
- **PRAW** - Parallel Programming for Multi-Core Architectures (Programowanie równoległe na architekturach wielordzeniowych)
